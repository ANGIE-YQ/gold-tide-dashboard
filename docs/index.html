📖 新手指南 · 看懂这张看板 ▼

🎯 第一步：看顶部的"今日交易决策" — 这是最重要的信息。它告诉你今天应该做什么（做多/做空/观望），以及止损止盈价。

🔢 第二步：理解概率 — P(涨) 是模型预测未来 10 个交易日价格上涨的概率。范围 0-100%，50% 是中间值。

  • P(涨) > 65% → 强烈看多信号
  • P(涨) 35%-65% → 观望（模型不确定）
  • P(涨) < 35% → 强烈看空信号

🧭 第三步：看懂 ±En·v — 这是"裁判"，独立验证主力模型的判断。

±（状态优势度）
范围 -1 到 +1。正数=上涨力量强，负数=下跌力量强。接近 0 时最重要——意味着多空平衡，即将翻转。
En（能量序列）
每个"潮汐"的能量 = 价格涨跌幅度 × 持续时间。上涨和下跌分开看，数值越大说明那个方向的力量越强。
ʋ（趋变系数）
大于 1 = 趋势在增强。小于 1 = 趋势在衰减。用来看"这一波行情还有没有后劲"。

🔄 第四步：用决策矩阵 — 把两个模型的信息放在一起看：

  • 主力说买 + 裁判说"归零" = 🟢 最可靠信号，可以多买
  • 主力说买 + 裁判没说话 = 🟡 标准信号，正常买
  • 主力说观望 = ⭕ 什么都不做
